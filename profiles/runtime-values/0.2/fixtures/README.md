# Runtime-values 0.2 fixtures

This bounded corpus exercises the five profile families (`runtime-contracts`,
`runtime-targets`, `runtime-activations`, `runtime-bindings`, and
`runtime-observations`) through complete CSMI 0.1 semantic documents. The
checked-in `documents/valid` cases cover portable and artifact-specialized
Node contracts, `process.argv` index origins, CPython `os.environ`, unknown or
unsupported targets, range conditionality, conflicting candidates, mixed
partitions, worker copy/shared stores, mutation, lexical shadowing, lookup
near-misses, dynamic keys, open effects, and a deliberately closed synthetic
proof. `documents/semantic-invalid` cases remain structurally valid while
violating one document-level invariant. `valid` and `invalid` contain raw
profile payloads for schema-only negotiation.

All source/resources, artifact bytes, reviews, evidence URIs, and runtime
observations are synthetic conformance material. Their SHA-256 values are real
hashes of the named synthetic inputs; they are not claims about an installed
Node/Python runtime, a production semantic pack, or a deployed system.
Identity records use the versioned synthetic-locator scheme, and locator
digests commit to that scheme as well as kind and locator. The negative corpus
therefore includes a same-hash/different-scheme join to keep opaque digest
equality from being treated as portable identity evidence.

Regenerate deterministically with:

```sh
python3 scripts/runtime-values-fixtures.py
python3 scripts/runtime-values-fixtures.py --check
```

The second command is non-mutating and fails if generated bytes differ from
the checked-in fixtures. Full structural, semantic, digest, join, policy, and
independent-consumer checks run with:

```sh
python3 scripts/validate-runtime-values-0.2.py
```
