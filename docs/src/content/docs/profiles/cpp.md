<span class="csmi-label csmi-label--normative">Normative profile</span>

`csmi.c-cpp-resolution` version `0.1.0` defines exact C/C++ resolution context.
The separate C++-only `csmi.cpp` vocabulary and `csmi.cpp.declaration` identity
scheme cover the
canonical `std::string` alias target and exact copy-constructor and
copy-assignment declaration keys.

Header spellings, displayed signatures, native database ids, and same-named
custom types are not identity evidence. Missing or incomplete artifact and
resolver inputs fail closed.
