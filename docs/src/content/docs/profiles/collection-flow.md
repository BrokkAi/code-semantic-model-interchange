`csmi.collection-flow` version `0.1.0` describes generic collection and
higher-order transfer semantics without selecting one language's collection API
as the portable model. Structured identities and ordered type arguments remain
intact. Callback inputs belong to a distinct invocation boundary; product
components require explicit semantic evidence.

The profile is independently versioned and uses CSMI `0.1` / `0.1-json`.
Unsupported required semantics remain uninterpretable. Partial or unknown
coverage cannot become an empty complete summary.
