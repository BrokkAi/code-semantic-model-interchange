<span class="csmi-label csmi-label--normative">Normative profile</span>

`csmi.value-transfer` version `0.1.0` adds identity-separating meaning to
selected core transfers while keeping ordinary core flow, aliasing, mutation,
and completeness separate. It also defines exact type-value semantics and
implicit-operation facts.

The profile preserves unknown operation selection, move invalidation, and value
preservation as typed uncertainty. Required unsupported semantics are
uninterpretable, never an empty or favorable result.
