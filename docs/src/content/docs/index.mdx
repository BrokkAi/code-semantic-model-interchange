<section class="csmi-intro">
  <p class="csmi-intro__lead">
    CSMI lets one tool describe selected declarations and behavior of a software
    artifact so that another tool can interpret the same knowledge without
    sharing its compiler, intermediate representation, or analysis engine.
  </p>
  <p>
    The repository is the source of truth. This site is a navigable rendering
    of version-controlled specification material and links every normative
    artifact back to its schema and source revision.
  </p>
</section>

## Core model

<p class="section-deck">
  A deliberately small semantic core, with explicit identity, uncertainty, and
  extension boundaries.
</p>
